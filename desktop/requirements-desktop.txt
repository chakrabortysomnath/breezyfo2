# Covered Call Analyser — Desktop build dependencies
#
# Consolidated, cleaned dependency set for running the app locally on a laptop
# (backend + frontend + native desktop window), assuming Python is already
# installed. Install into a virtualenv via desktop/setup.ps1.
#
# Versions are LOWER-BOUND ranges (not hard pins) so pip installs wheels that
# match the local interpreter. The original backend/requirements.txt hard-pinned
# old builds (fastapi 0.104 / pydantic 2.5 / numpy 1.26 / scipy 1.11) that have
# no wheels for Python 3.12/3.13 and would fail to install there.
#
# Cleaned up vs the original backend/requirements.txt:
#   - ADDED  breeze_connect (imported everywhere but was missing from backend reqs)
#   - ADDED  pywebview      (native desktop window shell)
#   - DROPPED sqlalchemy, psycopg2-binary, alembic, python-jose, passlib,
#            google-auth, email-validator  (no DB / JWT / OAuth code exists)
